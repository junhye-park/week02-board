# 사기시그널

의심스러운 문자와 메시지에 포함된 금융사기 위험 신호를 분석하고 기록하는 Flask 기반 웹 서비스입니다.

## 프로젝트 소개

스미싱, 보이스피싱, 투자사기 등의 메시지에는 송금 요구, 기관 사칭, 개인정보 요구, 외부 링크처럼 반복적으로 등장하는 위험 신호가 있습니다.

사기시그널은 입력된 메시지에서 이러한 키워드를 탐지하여 위험점수와 위험등급을 제공합니다. 분석 결과는 MySQL 데이터베이스에 저장되며 검색·조회·수정·삭제할 수 있습니다.

> 이 프로젝트는 금융사기 예방 학습을 위해 제작되었으며, 실제 금융사기 여부를 확정하지 않습니다.

## 주요 기능

* 금융사기 의심 메시지 입력
* 스미싱·보이스피싱·투자사기 등 유형 선택
* 위험 키워드 자동 탐지
* 0점부터 100점까지 위험점수 계산
* 낮음·주의·위험의 3단계 등급 제공
* 분석 결과 등록·조회·수정·삭제
* 메시지와 메모 검색
* 사기 유형 및 위험등급 필터
* 위험등급별 통계 대시보드
* 반응형 웹 디자인
* 환경변수를 이용한 데이터베이스 정보 관리

## 위험도 분석 기준

메시지에 포함된 위험 키워드마다 점수를 부여하고 합산합니다.

주요 탐지 항목은 다음과 같습니다.

* 송금 또는 입금 요구
* 계좌와 대출 관련 표현
* 검찰·경찰·금융감독원 사칭
* 비밀번호·인증번호·개인정보 요구
* 앱 설치 및 인터넷 주소 접속 유도
* 원금 또는 고수익 보장
* 긴급하거나 즉각적인 행동 요구

| 위험점수    | 위험등급 |
| ------- | ---- |
| 0~29점   | 낮음   |
| 30~59점  | 주의   |
| 60~100점 | 위험   |

## 데이터베이스 기능

다음 SQL 명령을 직접 사용하여 CRUD 기능을 구현했습니다.

* `SELECT`: 분석 기록과 통계 조회
* `INSERT`: 새로운 분석 결과 저장
* `UPDATE`: 기존 기록 수정 및 재분석
* `DELETE`: 분석 기록 삭제

## 실행 방법

### 1. 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 2. 환경변수 설정

프로젝트 최상위 경로에 `.env` 파일을 생성하고 자신의 데이터베이스 정보를 입력합니다.

```env
DB_HOST=localhost
DB_PORT=3307
DB_USER=root
DB_PASSWORD=본인의_비밀번호
DB_NAME=week02_board
```

### 3. 데이터베이스 생성

`schema.sql`을 실행하여 데이터베이스와 테이블을 생성합니다.

### 4. Flask 서버 실행

```bash
python app.py
```

브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.
